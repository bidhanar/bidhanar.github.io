Helicopter Trim Analysis

Course Project — Apr 2023

Overview

Computed trim solutions for a rotor system and estimated dynamic properties using numerical methods.

What I did

  • Balanced forces and moments on the hub and transferred them to the rotating frame.
  • Used Newmark’s algorithm (time-marching) to calculate blade flap frequency.
  • Computed trim parameters from an initial guess using residual methods and Jacobian matrices.
