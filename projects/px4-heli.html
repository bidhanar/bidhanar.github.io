PX4 Helicopter Simulator

PX4 · Gazebo · ROS · Simulation

Summary: A lightweight rotorcraft simulation environment built to test controllers and logging for rotorcraft experiments. The project includes example Gazebo worlds, PX4 parameter sets tuned for rotorcraft, and tools to log and replay flights for analysis.

Features

  • Rotorcraft-specific Gazebo models and worlds
  • PX4 parameter sets and sample missions
  • Data logging, plotting scripts, and replay utilities

How to run (short)

git clone https://github.com/bidhanar/helisim
cd helisim
# follow README.md in the repo to build and run the Gazebo worlds
